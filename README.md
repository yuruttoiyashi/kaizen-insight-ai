# Kaizen Insight AI

Kaizen Insight AI は、物流・倉庫・事務現場で発生する「ヒヤリハット」「作業上の困りごと」「改善提案」を一元管理し、AIによる要約・分類・改善アクション提案につなげる業務改善支援アプリです。

現場で発生した小さな気づきを記録し、カテゴリ・優先度・対応状況ごとに可視化することで、属人的になりやすい改善活動をデータとして蓄積できるように設計しました。

## 制作目的

現場では、日々の作業の中で「危ない」「効率が悪い」「確認が重複している」「新人が迷いやすい」といった小さな課題が発生します。

しかし、それらの情報は口頭共有やメモで終わってしまい、改善につながる前に埋もれてしまうことがあります。

本アプリでは、現場の気づきを簡単に登録し、AIによって内容を要約・原因整理・改善アクション化することで、現場改善の流れを支援します。

## 主な機能

- 改善提案・ヒヤリハットの登録
- カテゴリ別管理
  - 安全
  - 品質
  - 効率
  - 教育
  - 設備
  - 人員配置
- 影響度・緊急度による優先度判定
- ステータス管理
  - 未対応
  - 対応中
  - 完了
  - 保留
- ダッシュボードでの件数可視化
- カテゴリ別・優先度別の集計
- AIによる要約・原因候補・改善アクション提案
- CSVデータの取り込み・出力想定

## 画面構成

### ダッシュボード

改善投稿数、未対応件数、高優先度件数、完了件数などをカード形式で表示します。  
カテゴリ別の件数や最近登録された改善提案も確認できます。

### 改善一覧

登録された改善提案・ヒヤリハットを一覧で確認できます。  
カテゴリ、ステータス、優先度で絞り込みできる想定です。

### 改善登録

現場で発生した課題や気づきを登録します。  
発生日、工程、カテゴリ、内容、影響度、緊急度、提案者などを入力できます。

### 改善詳細

登録内容の詳細を確認し、AI要約、原因候補、改善アクション案、担当者、期限、対応状況を管理します。

### レポート

月別・カテゴリ別・優先度別の傾向を確認し、改善活動の振り返りに活用します。

## 工夫したポイント

- 物流・倉庫現場で実際に起こりそうな課題を題材にしたこと
- 現場担当者でも使いやすいシンプルなUIを意識したこと
- 改善提案を「投稿して終わり」ではなく、対応状況まで追える設計にしたこと
- AIを単なるチャットではなく、業務改善の補助として活用する設計にしたこと
- ダッシュボードで管理者が状況を把握しやすい構成にしたこと
